# ComfyUI MiniMax FullStack

[English](README.md) · [安装与完整依赖](docs/INSTALL.md) · [中文操作手册](docs/MANUAL.zh-CN.md) · [API 接入](docs/API.md) · [致谢](CREDITS.md)

**把一个意图与参考素材，贯通成一段可预览的视频。**

MiniMax H3 Full Stack 将素材管理、可选参考图生成、提示词设计、H3 音视频生成、预览、插帧、放大与导出整合到一个 ComfyUI 工作面板。支持一键贯通，也支持在图片和提示词阶段停下来检查、修改，再继续。

最重要的能力是 **“只输入意图，让模型围绕真实参考素材设计视频提示词”**：本地视觉语言模型读取上传的素材，按 MiniMax 官方基础／多参考提示词规范组织主体、参考关系、镜头动作与声音，而不只是扩写一句话。REF 提示词会校验素材标签，并要求把重要参考落实到镜头描述。也可改用兼容 API 设计文案；图片和视频仍在本地生成。

## 核心功能

- **全栈式视频生成**：同一节点管理参考素材、H3 模型、LoRA、采样、实时预览和最终导出。
- **素材到镜头的提示词设计**：多图 REF、自动路由／文本／关键帧入口；优化全文可查看、编辑、审核，或连接外部文本节点。
- **参考图生图挂载节点**：选择 Krea2 或 Qwen Image 2.1、模型、画幅与 LoRA；一个输出可接多个图片位置。空位自动接收，有原图时由你选择应用。
- **总体参考一键模式**：勾选图片，分别填写物象意向与人物／物品／场景类型。人物参考不强迫蛋糕、庭院等素材带人物；每格可选画幅，默认与视频一致。
- **检查与重抽**：先生成素材停下检查，再用新意图设计视频。改变 LoRA、权重或种子，不会无故重跑已有效的图片提示词。人物卡片为单张三视图，模板可编辑。
- **中文优先**：默认中文界面和中文描述，保留 H3 必需的协议字段与参考标签；英文可选。
- **本地 / API 切换**：主节点与生图节点共用配置入口；密钥不写工作流，API 看图需明确勾选。本版不提供 DeepSeek 预设或测试密钥。
- **产出可见**：最终 MP4 可暂停、拖动，后处理有进度；启用资产系统后可在资产栏查看，外接保存视频节点随视频任务执行。

## 最短上手路径

1. 按 [完整依赖清单](docs/INSTALL.md) 安装插件、上游节点和模型。**四个 Python 包不是完整依赖**，本仓库不附带模型。
2. 重启后端并刷新网页，添加 **MiniMax H3 Full Stack**。
3. 在 **设置 → 视频模型** 选择 H3 主模型、编码器、视频与音频 VAE；步数需与模型、蒸馏 LoRA 配套。
4. 上传素材、填写意图，先点 **生成视频提示词** 检查全文。本地／API 在 **设置 → 提示词模型 · 本地 / API** 配置。
5. 点 **生成视频**；总体参考可先 **生成素材 · 停下检查**，也可 **一键生成视频**。
6. 默认产出在 `output/H3FullStack/`。资产栏需开启 `--enable-assets`，或点 **启用原生资产登记**，队列为空时重启。

详细连接方式、提示词复用、三视图模板、参数和排错见 [中文操作手册](docs/MANUAL.zh-CN.md)。

## 2.9.0 更新

增加 API 文案入口，修复插帧后的导出与显示链路：逐帧编码、逐帧 Lanczos 放大，避免额外堆积整段放大浮点图片；原片保存后先预览；外接 VIDEO 改为文件输出，兼容保存时可直接转封装；结果按原生资产格式登记；一键生成包含实际连接的下游保存节点。

已通过 **221 项 Python、86 项前端测试**，并实测最小量 RIFE → MP4 → Lanczos → 外接保存 → 资产登记。测试不代表所有硬件、模型与视觉效果都已验证，详见 [验收记录](docs/VALIDATION.md)。
