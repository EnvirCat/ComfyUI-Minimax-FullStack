# 中文操作手册 · 2.9.0

[安装与完整依赖](INSTALL.md) · [API 接入与隐私](API.md) · [English manual](MANUAL.en.md)

## 1. 面板怎么用

添加 **MiniMax H3 Full Stack**。顶部是常改的生成模式、时长、视频画幅、分辨率、意图／提示词和视频 LoRA。下面三个页签：

- **素材**：九个图片位置、视频和音频参考；总体参考、单格类型／画幅与外接生图入口。
- **提示词／预览**：优化后的完整文案、审核开关、最终播放器。
- **设置**：本地／API、语言、视频模型、采样、注意力、输出与后期。不常改的项目默认折叠。

主面板的 LoRA 用于 **H3 视频模型**；总体生图和外接生图都有自己的 **图片 LoRA**，两者不是一份设置。

## 2. 用现成素材生成视频

1. 上传或拖入图片、视频、音频。图片位置顺序对应 `<Picture 1>` 等实际参考标签，不要在提示词里编造不存在的序号。
2. 写清楚意图：时长、主体、素材用途、动作、镜头和声音。例如：庭院中桌面摆放第二张图片的蛋糕，镜头缓慢推近，不出现人物。
3. 选择 REF 并确认 **REF2VA 模型**；Auto 会按实际素材路由。基础关键帧／文本模式使用配套模型分支。
4. 设置提示词模型，开启视频提示词优化，先点 **生成视频提示词**。这一步不生成完整视频。
5. 在 **提示词／预览 → 查看／编辑完整提示词** 检查镜头。修改后勾选 **使用已审核的优化提示词**，再点 **生成视频**。

REF 应同时写清主体定义、保留／迁移关系，以及参考如何真正参与镜头。程序会校验协议和素材引用，但不能代替人工确认物体外观、剧情和视觉效果。

关闭优化不是“自动使用上次文案”的万能开关：它使用当前输入的文字。要复用检查后的文案，选用审核后的提示词；修改素材或意图后应重新检查。

中文默认指描述内容，`subject_definitions`、`<Picture N>` 等协议名仍保留。原文对白不强行翻译。

## 3. 总体参考：从素材到视频

1. 在素材页开启 **总体参考**，可上传一张画风图。默认仅学习媒介、色调、光影和光学质感。
2. **参考图片中人物** 开启时，人物类素材学习发型、服装、配饰、妆容等；不把原背景与姿势强行复制。默认不写脸部结构，脸部身份可交给 LoRA。这是提示词学习后的文生图，不是强制图像编辑，也不保证像素级一致。
3. 勾选要自动生成的图片，分别填意向，并选 **人物／物品／场景／组合画面** 等类型。院子、蛋糕用场景或物品类型，不要因总意图含人物就让每张图都变成人像。组合画面需要人物时明确选择对应类型。
4. 每格画幅默认 **和视频一致**，也能单独选；在总体生图参数选择 Krea2／Qwen Image 2.1、模型文件、图片 LoRA、步数与清晰度。
5. **生成素材 · 停下检查**：只完成素材，便于查看、修改、重新抽卡。之后可修改顶部总意图，再点 **生成视频提示词**，让新意图使用已生成素材规划视频。
6. **一键生成视频**：素材 → 视频提示词 → H3 视频 → 后处理。在进度中可看当前阶段，期间生成的文案可在提示词页查看。

总体批量生成与外接生图不要同时接管同一个勾选位置。重新批量生成前断开这些外接输入；总体素材完成后，可以再挂外接生图改某一张。

## 4. 挂载 H3 参考图生图

点击图片框左上角圆点挂载生图节点，或从节点菜单添加 **H3 参考图生图**，把 `IMAGE` 输出接到一个或多个图片位置。

生图节点可输入意向／提示词，可选参考图，选择模型、比例、LoRA、权重、步数、分辨率与种子。三种约束：

| 模式 | 用法与边界 |
| --- | --- |
| 完全复刻 | 必须有参考图；反推主体、服装、姿势、构图、背景和光影再文生图。名字表示尽量完整反推，不保证逐像素复刻。 |
| 人物卡片 | 学习人物服装与造型，生成**一张**正面、侧面、背面合成卡片；模板可自行编辑。默认远景全身、完整头脚和上下留白，不描述五官结构。 |
| 参考画风＋输入意向 | 只迁移风格，由你的文字决定主体。无参考图时直接使用原文提示词，不暗中重写。 |

先 **设计提示词** 检查编辑，再 **生成／再抽一张**。有效草稿在改变 LoRA、权重、种子或模型时继续复用；改变参考、意向或模式才需要重设计。若想完全用自己的文字，编辑草稿后再生成。

空图片位置自动安装结果；已有图片时要点 **应用此图片**，不无声覆盖。三视图若仍裁切，检查自定义模板是否覆盖默认留白，并提高横向画幅／适当增加分辨率。

人物 LoRA 在同画面多人时可能污染其它角色；不要假定两个 LoRA 能自动分别绑定两个人。可先做单人资产，再让 H3 REF 合成并明确参考关系。

## 5. 本地模型与 API

主节点 **设置 → 提示词模型 · 本地 / API**，生图节点同名按钮。默认本地。本地 GGUF、mmproj 和 handler 在折叠的本地提示词设置里选择；API 的地址、模型、密钥与视觉授权见 [API 手册](API.md)。

纯文本 API 不会看图：有参考素材时需本地视觉模型先分析，或显式启用支持视觉的 API。测试文本连接只验证接口，不代表视觉能力或整段视频已通过。

进入视频采样前会释放本地提示词模型。重复执行的问题应检查保存的诊断、模型／handler 与内存；不要额外挂不明“清显存”节点替代正确生命周期。

## 6. 预览、插帧与保存

采样预览是阶段性图片／帧段，不等于完整时长。最终 MP4 出现后可暂停、播放、拖动；时间信息以最终文件为准。RIFE 完成后还要编码和可能的放大，进度会显示这些阶段，不能看到 `Comfy-VFI done` 就认为全部结束。

H3 原始视频 24fps，帧数需满足 `5 + 17n`；输入 10 秒对应 243 帧，实际 10.125 秒。RIFE 2 倍中间可能报告 485 帧，插件补最后一帧到 486 帧、48fps，保持 10.125 秒，不加速原音频。2 秒会对齐到 56 帧、约 2.333 秒。

默认文件位置：

```text
output/H3FullStack/
  H3_<时间>_<随机标记>_<种子>_base.mp4
  H3_<时间>_<随机标记>_<种子>_upscaled.mp4  # 开启放大才有
  H3_<时间>_<随机标记>_<种子>.json         # 参数与提示词
  prompts/                                  # 已完成或中间提示词记录
  diagnostics/                              # 失败诊断
  总体参考图/                               # 批量素材与记录
  参考图生图/                               # 单图结果
```

输出目录和前缀可设置。原视频即使放大随后失败，也保留在磁盘并可先预览。标准 VIDEO 输出可接原生 **保存视频**；一键视频执行会包含实际连接的下游节点，而素材／提示词检查步骤不会误执行它们。兼容 Auto 保存可转封装已有文件；改变编码格式可能重新编码。

资产栏需开启原生资产系统，见安装手册。缩略图没显示时先检查实际 MP4 与资产开关；不要误删已经成功的作品。

## 7. 中断、复用与排错

保存工作流和素材。总体任务会保存已完成阶段；意图、素材顺序／文件状态、模式、时长与语言保持匹配时可复用已完成提示词。断电／后端崩溃不支持恢复到扩散采样的某一帧，未完成阶段需要重跑。

| 症状 | 检查方向 |
| --- | --- |
| 资产栏空，但有 MP4 | 启用 `--enable-assets` 或按钮偏好后重启，等后台扫描；确认输出在 ComfyUI/output 下。 |
| 外接保存节点空 | 刷新到 2.9.0；确认连接 VIDEO，不是 STRING／提示词；执行视频步骤而非仅设计提示词。 |
| 插帧后似乎卡住 | 查看编码／放大进度与可见后端日志。大尺寸、长片、DLSS、磁盘 I/O 仍可能慢；先用小尺寸关闭放大定位。 |
| 物品变成人像 | 单格选择物品／场景类型，去除该格人物 LoRA，检查生成草稿。 |
| 提示词不可用 | 查看全文、截断提示和 diagnostics；修正 context／handler，或编辑草稿，不静默拿错误文案生视频。 |
| 缺失节点／模型 | 按完整依赖清单检查原生节点与文件，编码器／VAE／LoRA 必须配套。 |
| API 401/403/429/404 | 核对该接口的密钥、账号权限／额度和模型 ID；远端错误正文不会直接回显。 |
| 浏览器仍显示旧版 | 后端重启后刷新；确认没有重复插件目录。 |

排错先用 2 秒、0.1 MP、小尺寸素材测试连通性；这不是正式画质预设。正式生成再提高参数。提交问题时附版本、阶段、经过脱敏的报错和配置，不附密钥或私人素材。
